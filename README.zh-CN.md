# 更快的确定性 3SUM 算法与加权缓存模型的优化极限

王炯涵（Jionghan Wang），中国科学技术大学  
wangjh1@ustc.edu.cn

本项目包含两个相互衔接的结果：构造一个具有更小认证时间指数的完整
3SUM 判断算法，并用 Lean 定位其加权缓存成本模型的最优指数。

完整算法的确定性时间界为 **O(n^1.920279408185)**，改进了此前认证的
O(n^1.92027942)。输入范围是：对任意固定自然数 κ，输入整数绝对值
不超过 n^κ；计算模型是项目中明确定义的、字长为 O(log n) 的 word-RAM。
正确性使用原始 3SUM 语义：三个输入位置必须两两不同。

设 E* 为项目中六项成本目标在全部合法参数上的下确界，则有

```
1.92027940818 ≤ E* < 1.9202794081848.
```

这个区间宽度为 4.8×10⁻¹²。相对完整求解器的认证指数，继续在该模型中
调参能够节省的指数至多为 5×10⁻¹²。这里量化的参数包括全部正熵三元概率
分布、全部实数单调加性权重、所有合法公共阈值和非负 Gibbs 参数。
因此，这是这套成本模型的优化界限；改变缓存架构、查询重构或成本分析
需要另立模型和定理。

目标函数除以熵 H，因此 H>0 是显式定义域条件。用于建立下界的区域
覆盖定理则包含整个概率单纯形，包括零熵边界。熵不等式先消去权重、阈值和
Gibbs 参数，随后用 16,680 个区域覆盖全部概率分布。每次细分都有
覆盖证明，每个区域的不等式都有带余项界的精确区间证书，零概率边界也
在证明范围内。Python 只生成候选数据，Lean 内核负责检验数据及其含义。

公开入口为 `Submission.lean`：

| 定理 | 内容 |
|---|---|
| `Race.bound` | 完整 RAM 程序的正确性与改进时间界 |
| `Race.cache_optimum_interval` | 模型最优指数的双侧区间 |
| `Race.cache_optimization_limit` | 任意合法参数均不能突破给定下界 |
| `Race.remaining_exponent_gain` | 此模型剩余调参空间的精确上界 |
